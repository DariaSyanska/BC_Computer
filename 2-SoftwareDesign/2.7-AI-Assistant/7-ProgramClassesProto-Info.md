# Критерії верифікації прототипу програмних класів
1. **Повнота методів**: Чи реалізують методи класів усі функціональні вимоги (FR)?
2. **Типізація**: Чи скрізь вказані типи даних для атрибутів та результатів методів?
3. **Інкапсуляція**: Чи правильно використані модифікатори доступу (- для полів, + для методів)?
4. **Зв'язки**: Чи відповідають зв'язки (агрегація, асоціація) логіці системи?
5. **Узгодженість**: Чи немає розбіжностей між назвами класів та UseCase-діаграмою?
