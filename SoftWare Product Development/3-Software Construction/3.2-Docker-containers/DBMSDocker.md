### 2.3.2 Робота з Docker-контейнером СКБД

**Виконані кроки:**

1. **Завантаження образу:** Виконано команду `docker pull postgres` для отримання останньої версії образу СКБД PostgreSQL.
2. **Запуск контейнера:** Створено та запущено контейнер з назвою **syanska-postgres**.
3. **Налаштування портів:** Через те, що стандартний порт 5432 на вашому комп'ютері вже був зайнятий, зовнішній порт було перенаправлено на **5455** (`-p 5455:5432`).
4. **Змінні середовища:** Встановлено пароль адміністратора `POSTGRES_PASSWORD=1234`.
5. **Режим запуску:** Контейнер запущено у фоновому режимі (detached) за допомогою прапорця `-d`.
6. **Перевірка:** Стан контейнера перевірено командою `docker ps`, яка підтвердила статус "Up".

**Графічне підтвердження:** Результат виконання команди представлено у файлі `DBMSDockerExec.jpg`.
