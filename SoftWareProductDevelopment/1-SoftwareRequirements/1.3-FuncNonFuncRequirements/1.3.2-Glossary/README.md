# Понятійний апарат (глосарій)

| Термін | Визначення |
| :--- | :--- |
| **Якість сну** | Сукупність показників тривалості та неперервності сну, що впливають на відновлення організму. |
| **Ергономіка** | Наука про пристосування робочих місць для найбільш безпечної та ефективної праці. |
| **Сет-поінт цілі** | Визначена користувачем кількість слів або годин, яку необхідно досягти за один робочий цикл. |
| **KPI письменника** | Кількісні показники продуктивності (слів/год, глав/місяць), що використовуються для оцінки прогресу. |
