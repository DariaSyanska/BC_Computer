# Функціональні вимоги

| Ідентифікатор | Опис вимоги (Суб'єкт - Дія - Об'єкт) |
| :--- | :--- |
| **FR1 (Сон)** | |
| FR1.1 | Користувач вводить час засинання та час пробудження. |
| FR1.2 | Система розраховує тривалість фаз глибокого та швидкого сну. |
| FR1.3 | Система візуалізує статистику якості сну за обраний період. |
| **FR2 (Безпека)** | |
| FR2.1 | Система відстежує час безперервної роботи користувача за комп'ютером. |
| FR2.2 | Система надсилає сповіщення про необхідність виконання вправ для очей. |
| FR2.3 | Користувач переглядає інтерактивний довідник з ергономіки робочого місця. |
| **FR3 (Творчість)** | |
| FR3.1 | Письменник створює нові глави літературного твору в редакторі. |
| FR3.2 | Система автоматично підраховує кількість слів у поточному сеансі. |
| FR3.3 | Система встановлює та відстежує щоденну ціль за кількістю слів. |
| **FR4 (Статус)** | |
| FR4.1 | Система генерує цифрові відзнаки за досягнення літературних цілей. |
| FR4.2 | Користувач ділиться прогресом написання твору в соціальних мережах. |
