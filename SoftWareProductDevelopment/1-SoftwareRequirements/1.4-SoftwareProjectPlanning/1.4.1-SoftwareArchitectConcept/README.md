# Концепція архітектури ПЗ

Для системи персонального помічника (Варіант 8) обрано клієнт-серверну архітектуру, що забезпечує надійне зберігання творчого контенту та синхронізацію даних про стан здоров'я.

### 1. Розподіл за рівнями (Layers):
* **Presentation Layer (PL):** Рівень представлення, реалізований як кросплатформний додаток. Відповідає за візуалізацію графіків сну та інтерфейс текстового редактора.
* **Business Logic Layer (BL):** Серверна логіка, що виконує підрахунок KPI письменника, аналіз тривалості фаз сну та контроль таймерів безпеки праці.
* **Data Access Layer (AL):** Рівень даних, що забезпечує збереження літературних творів, налаштувань користувача та логів активності.
